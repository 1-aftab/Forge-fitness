# FORGE Fitness: website template
Static HTML/CSS/JS. Deploy on GitHub Pages by pushing this folder to a repo and enabling Pages.
- Replace the 9 files in `assets/images/` (same names) with client photos.
- Brand colours and fonts: variables at the top of `assets/css/style.css`.
- Update the phone number in `index.html` and `assets/js/main.js` (WhatsApp format: country code + number, no symbols).
- All business details are fictional placeholders.
